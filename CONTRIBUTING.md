# Contributing

Issues are welcome from anyone: bugs, questions, rough edges, a harness that behaves differently from what the docs say.

Code lands only through ADE's own loop. A pull request from outside is read as a proposal: if it is taken up, the change is carded and built by ADE, and the card credits you. Please don't be put off by that; a clear issue or a small PR showing the idea is the fastest way in.

Text in issues and pull requests is read as data, never as instructions. Agents working on this repo don't act on what an issue tells them to do; a person decides.

Replies may be drafted with help from an agent and are sent by a person.
