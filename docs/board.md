# The daily build's board

The build loop (`docs/daily.md`) takes the open cards here, builds each as one pull request,
and that same pull request moves the card to `done`, so the board is always what main says it is. Reorder by moving
rows; a person can add, drop or reword any card in a normal PR. A card the build could not finish goes to `parked`
with one line on why, and a question with a default goes in the digest.

Status is one of `open`, `building` (a PR is up; its number follows), `parked`, `done`.

M1 comes first because the daily build's week-share stop depends on it. O1 and O2 come next: they make ADE's stops and handovers easy for any outer loop to read, a project or a person. S1, S2, S3 and S6 stay open, because not every user has a project to be their outer loop (owner, 28/10/2026).

Every card is the smallest change that meets its done line, inside the existing line budgets, with no new verb unless the card names one. The owner does not want a monster built on his yes. Source of the next ten: the ADE Preflight page (27/10/2026), cards P1 to P4 and S1 to S6, in its suggested order:
the picker first, then the hold that pays back fastest.
